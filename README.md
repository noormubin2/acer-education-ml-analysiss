# Educational Outcome Machine Learning Analysis

This repository contains the machine learning analysis completed for
RMIT Case Studies in Data Science – Individual Task 1.

## Case Study
The analysis was developed in relation to a Data Scientist role at the
Australian Council for Educational Research (ACER).

## Datasets
1. UCI Student Performance
   https://archive.ics.uci.edu/dataset/320/student+performance

2. UCI Predict Students' Dropout and Academic Success
   https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success

## Machine Learning Models
- Logistic Regression
- Random Forest

## Evaluation
Models were evaluated using:
- Accuracy
- Macro F1-score
- Confusion matrices
- Class-level precision and recall

## Files
- `analysis.ipynb` – complete analysis workflow
- `model_performance.png` – comparison of model performance
